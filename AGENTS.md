# Instrucciones del proyecto

Leer y seguir [Agente.md](Agente.md). El frontend Angular 22 de demostración está construido. El usuario confirmó que importó `database/cochasabor.sql` en XAMPP/phpMyAdmin y que se crearon las tablas y se cargaron los datos de demostración. El backend Node.js/Express para MariaDB ya existe; la etapa actual es integrarlo con Angular y verificar lectura pública, autenticación/cuentas, reseñas y favoritos de extremo a extremo. Hasta completar el adaptador HTTP, el frontend sigue usando repositorios y persistencia locales de demostración. La tabla `user_sessions` es un añadido al script SQL; al aplicarla, informar que en la base ya existente basta con ejecutar ese bloque `CREATE TABLE`, sin reimportar todo el script. El chatbot y despliegue siguen pendientes.
