# Avance de COCHASABOR

Alcance vigente (actualizado el 16 de noviembre de 2026): la base MariaDB se importó en XAMPP y el usuario confirmó la carga de tablas y datos demo. La etapa actual agrega un chatbot con Ollama Gemma 3, limitado a preguntas respaldadas por el contenido y uso de CochaSabor. No desplegar.

Actualización del 16 de noviembre de 2026: el backend implementa registro, login/logout, sesión persistida en MariaDB, lectura/edición/baja lógica de la cuenta propia y usa esa sesión para autorizar reseñas y favoritos. Se agregó `user_sessions` al SQL; como la base ya estaba importada, falta ejecutar únicamente ese bloque `CREATE TABLE IF NOT EXISTS`. La integración Angular conserva el repositorio JSON y el almacenamiento local para el modo demo, y añade un botón para alternar con el modo API. Los lugares y reseñas principales, cuentas, reseñas nuevas y favoritos se conectan a Express; si MariaDB no tiene medios u horarios, se reutiliza solo la presentación visual del JSON demo por slug. Se agregó un asistente flotante; Express prepara contexto de las funciones del sitio y el catálogo público, y consulta Ollama con `gemma3:4b`. Las preguntas fuera de alcance o no respaldadas reciben una respuesta fija de abstención. Falta ejecutar la aplicación y comprobar el chat contra los servicios locales.

Correcciones comprobadas durante integración: el enlace de regreso al catálogo interpreta la URL como UrlTree; imágenes con fill evitan distorsiones; la primera imagen del catálogo/favoritos tiene prioridad; estados inactivos no anuncian títulos de error; confirmación de reseña requiere una reseña local existente; los títulos del detalle se conservan al cambiar fragmento.
